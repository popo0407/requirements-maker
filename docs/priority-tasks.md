# 最優先実装タスクリスト

エディタ、AI 支援、共同編集、コメント機能の「完璧な実装」に向けた詳細タスクです。

## 1. 高機能エディタ (Editor)

- [ ] **自動保存機能**: ユーザーがタイピングを止めて 2 秒後にバックエンドへ保存
- [ ] **保存ステータス表示**: 「保存中...」「保存完了」「オフライン」などの状態をツールバーに表示
- [ ] **Markdown プレビューの同期スクロール**: エディタとプレビューのスクロール位置を連動
- [ ] **ショートカットキー**: `Ctrl+S` での強制保存、`Ctrl+P` でのプレビュー切り替え
- [ ] **画像アップロード対応**: ドラッグ＆ドロップで S3 に画像をアップロードし、Markdown リンクを挿入

## 2. 本格的な AI 支援 (AI Assistance)

- [ ] **AI API 連携 (OpenAI/Anthropic)**: バックエンドの `aiService.ts` を本物の API に接続
- [ ] **フェーズ特化プロンプトの実装**:
  - アイデア -> 要件定義への構造化変換
  - 要件定義の曖昧さ・矛盾チェック
  - 要件に基づく設計書の自動生成
- [ ] **ストリーミング応答**: AI の回答をリアルタイムでエディタに書き込む（UX 向上）
- [ ] **コンテキスト共有**: 前のフェーズの内容を AI に渡し、一貫性のある提案を実現

## 3. リアルタイム共同編集 (Collaborative Editing)

- [ ] **WebSocket 通信の確立**: 編集内容を他のユーザーに即時ブロードキャスト
- [ ] **競合解決ロジック (CRDT/OT)**: 複数人が同時に同じ行を編集してもデータが壊れない仕組みの導入
- [ ] **プレゼンス機能**: 現在同じプロジェクトを開いているユーザーをアバターで表示
- [ ] **カーソル共有**: 他のユーザーのカーソル位置と選択範囲をエディタ上にリアルタイム表示

## 4. インライン・コメント機能 (Comments)

- [ ] **行単位のコメント投稿**: Monaco Editor の行番号横をクリックしてコメントを追加
- [ ] **コメントスレッド UI**: 右サイドバーにコメント一覧を表示し、返信できる UI を実装
- [ ] **リアルタイム通知**: 新しいコメントがついた際に WebSocket で即時通知
- [ ] **解決済みフラグ**: 議論が終わったコメントを「解決済み」として非表示にする機能

---

## 実装スケジュール案

1. **Phase A**: AI API 連携 & 自動保存 (単体での利便性向上)
2. **Phase B**: コメント機能 (レビューサイクルの確立)
3. **Phase C**: リアルタイム共同編集 (チーム開発への対応)
